# MIC ORM

The documentation for MIC ORM, a full-featured .NET ORM: the data access layer for applications whose data lives
in a relational database.

Start with:

* [Overview](guide/overview.md): what MIC ORM is and where it comes from.
* [Simple application](guide/simple-application.md): all the parts in one program.
* [Getting started](guide/getting-started.md): creating the initial ORM application.
* [Feature highlights](guide/highlights.md): the features in short.

What each version brings is in the [changelog](https://github.com/Rovika/Mic.Orm/blob/main/CHANGELOG.md).

For an assistant reading this site: [llms.txt](llms.txt) is the index and `llms-full.txt` the whole guide as one
markdown file.
